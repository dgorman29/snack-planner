# Features

Current behavior of the app. Update this file whenever a feature is added, changed or removed.

## Look and feel
- Cozy "Peach Jam" theme: blush background, outlined cards with a flat shadow, rounded Fredoka headings. Tabs are in a floating dark bar at the bottom; the current tab shows its name. The Log tab shows a count badge when prepped snacks need a rating.

## Install as an app
- Installable as a standalone app (Chrome on Android: menu > Install app). Opens full-screen with its own icon. Requires being online; there is no offline mode.

## Login
- Email and password sign-in (Supabase Auth). Accounts are created by the owner in the Supabase dashboard; public sign-up is disabled.
- All signed-in users share the same data. "Sign out" is next to the week label.

## Week tab
- "Suggest snacks" builds six suggestions: half from the library, half generated by Claude. "More ideas" appends three; "New set" replaces the list.
- "Library only" toggle skips the AI and picks only from saved snacks.
- Tier filters: Grab and go, 2-3 min, Weekend batch.
- A "Weekday dinner" filter pill shows only suggestions carrying that tag.
- Cards expand to show steps and ingredients. Selecting a card adds it to the week; selected cards can be marked prepped. Selected AI ideas are saved to the library automatically.

### Suggestion rules (`pickFromLibrary`)
- Cooldown: a snack is skipped for 3 weeks after it was made, or 1 week if its average rating is 2.6+ (loved).
- Previously refused snacks resurface after 3 weeks with a "Worth another try" note.
- Untried snacks get a score boost; longer gaps raise the odds.
- Vegetables are spread out so one vegetable isn't suggested twice in a set when avoidable.

## List tab
- Built from the selected snacks. Duplicate ingredients (same name and unit) are summed.
- Grouped by produce, dairy, pantry, frozen, other.
- Check items off, mark "have it" (remembered in the pantry list), add manual items, and "Copy as text".

## Log tab
- Prepped snacks can be rated Loved it, Ate some, or Refused. Ratings drive future suggestions.

## Library tab
- 14 seeded snacks. Search by title, vegetable or ingredient. Delete snacks.
- Tap a snack to expand it, like on the Week tab: shows the description (steps), ingredients and recipe link.
- "Edit" (shown when a snack is expanded) changes its name, description, time to prepare in minutes, and ingredients (one per line, e.g. "2 tbsp olive oil"; unchanged lines keep their shopping-list section, new ones are sorted automatically). Changes show on the Week tab and shopping list too; past weeks in History keep the name the snack had then.
- Add by URL: Claude reads the page and extracts ingredients and quantities.
- Add by hand: title, main vegetable, tier, optional "Weekday dinner" tag, one ingredient per line.
- "Weekday dinner" tag: toggle it on any snack from the library list; tagged snacks show it on their cards, and the Library and Week tabs have a filter pill for it. The tag is only a label and a filter; it does not change what gets suggested.
- "Add to this week" on any library snack selects it for the current week (it appears on the Week tab and feeds the shopping list). Tap "In this week" to take it back out. A new set of suggestions replaces the Week tab cards but a pinned snack stays selected and on the list and log.

## History tab
- Exposure meter per vegetable, out to 10 tries, with a "warming up" flag when recent ratings improve.
- Past weeks with each verdict. Weeks roll over automatically on Monday.

## Known limits
- No per-user data: every signed-in account sees and edits the same household data.
- All data is one shared set of rows, so simultaneous edits from two devices are last-write-wins.
- No automated tests.
