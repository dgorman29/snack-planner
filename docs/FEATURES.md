# Features

Current behavior of the app. Update this file whenever a feature is added, changed or removed.

## Week tab
- "Suggest snacks" builds six suggestions: half from the library, half generated by Claude. "More ideas" appends three; "New set" replaces the list.
- "Library only" toggle skips the AI and picks only from saved snacks.
- Tier filters: Grab and go, 2-3 min, Weekend batch.
- Cards expand to show steps and ingredients. Selecting a card adds it to the week; selected cards can be marked prepped. Selected AI ideas are saved to the library automatically.

### Suggestion rules (`pickFromLibrary`)
- Cooldown: a snack is skipped for 3 weeks after it was made, or 1 week if its average rating is 2.6+ (loved).
- Previously refused snacks resurface after 3 weeks with a "Worth another try" note.
- Untried snacks get a score boost; longer gaps raise the odds.
- Vegetables are spread out so one vegetable isn't suggested twice in a set when avoidable.

## List tab
- Built from the selected snacks. Duplicate ingredients (same name and unit) are summed.
- Grouped by produce, dairy, pantry, frozen, other.
- Check items off, mark "have it" (remembered in the pantry list), add manual items, and "Copy as text".

## Log tab
- Prepped snacks can be rated Loved it, Ate some, or Refused. Ratings drive future suggestions.

## Library tab
- 14 seeded snacks. Search by title, vegetable or ingredient. Delete snacks.
- Add by URL: Claude reads the page and extracts ingredients and quantities.
- Add by hand: title, main vegetable, tier, one ingredient per line.

## History tab
- Exposure meter per vegetable, out to 10 tries, with a "warming up" flag when recent ratings improve.
- Past weeks with each verdict. Weeks roll over automatically on Monday.

## Known limits
- No login: anyone with the URL can read and write the data.
- All data is one shared set of rows, so simultaneous edits from two devices are last-write-wins.
- No automated tests.
